Instructions

  1. Setup this machine.Choose the shared queue folder, confirm the render command, and install the Cinema 4D plugin. Custom Redshift/Octane setups can use a .bat/.cmd wrapper.
  2. Start DreamRender.Use the main toggle at the top. When it is green, this machine can render and monitor jobs.
  3. Submit from Cinema 4D.Open the DreamRender submitter, run Check Scene, review warnings, then submit. DreamRender stores submit history with the job.
  4. Watch the Dashboard.Rendering jobs, worker confidence, frame ownership, progress, failures, and repair actions live in the Dashboard tab.

Troubleshooting

Plugin missingClose Cinema 4D, click Install C4D Plugin, then start Cinema 4D again.
Worker offlineOpen DreamRender on that machine and start it again. If needed, use Restart in the Dashboard.
Nothing rendersCheck Health, queue permissions, renderer licenses, and that every worker can access the same project paths.
Black framesIf your renderer needs custom environment paths, set Cinema 4D Render Command to a .bat/.cmd wrapper that calls Commandline.exe with %*.
Wrong output pathDreamRender uses Cinema 4D Render Settings. Make sure all machines map projects and output folders identically.
EXR preview missingEXR files render fine, but previews need ImageMagick, OpenImageIO, or ffmpeg on the monitor machine.
Failed framesRead the failure summary, fix the cause, then use Retry Failed. Use Mark Failed Done only when outputs are verified.
Old scene renderedThe submitter saves first and records source-scene time. Check the job metadata if you suspect an old scene copy.
Different machine pathsDreamRender can be installed anywhere, but every worker must use the same queue path and must be able to read the same project/output paths.

About

DreamRender is lightweight render farm software for small Cinema 4D 2026 studios using Redshift or Octane.

It uses a shared folder as the queue, so machines can join, leave, pick up batches, and report progress without a central database server.

Renderer support: Redshift and Octane License: MIT App: local desktop control surface Submitter: Cinema 4D plugin Config: per-user settings, no hardcoded studio paths
